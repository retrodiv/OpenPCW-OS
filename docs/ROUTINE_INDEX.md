# Routine contract index

This generated index covers every global assembly entry reached through a
direct `CALL`/`JP` and every explicit boot or public entry. Dot-prefixed
labels are local basic blocks documented by their enclosing routine.

Each routine inherits the inputs, outputs, register policy, state, and
memory contract of its component below. Routine-local source comments refine
that contract where an operation has narrower preservation or boundary rules.
The source symbol supplies the concise action name; design and validation IDs
link to the detailed rationale and executable evidence.

## Component contracts

### BOOT

- Inputs: PCW bootstrap state and physical system sectors.
- Outputs: mapped resident and native modules with their documented entry selected.
- Registers: private boot context; routines publish only their explicit transfer result.
- State: FDC command state, paging ports, motor state, and boot progress.
- Memory: F000h boot sector, B000h stage two, protected blocks 3, 7, and 8.
- Design basis: `DES-BOOT-001`, `DES-BOOT-002`, `DES-MEM-001`.
- Public basis: `REF-PCW-BOOT`, `REF-PCW-IO`.
- Validation: `VAL-BUILD-LAYOUT`, `VAL-ARTIFACT-CONTRACTS`.

### RESIDENT

- Inputs: CP/M Page Zero, BDOS/BIOS register calls, or resident-shell command state.
- Outputs: CP/M-compatible return registers or transfer to the selected command.
- Registers: public calls follow the documented ABI; internal helpers treat AF, BC, DE, and HL as working unless their local comment preserves them.
- State: resident shell, SCB, bank mapping, interrupt chain, and native-service bridge.
- Memory: attached modules below F000h, cold source at F200h-F2FFh, and lifecycle/persistent common regions from F300h through FFFFh, all with build-checked ABI islands.
- Design basis: `DES-KERNEL-001`, `DES-BDOS-001`, `DES-SHELL-001`, `DES-IRQ-001`, `DES-ENTRY-001`.
- Public basis: `REF-CPM3-PG`, `REF-Z80-UM0080`, `REF-PCW-IO`.
- Validation: `VAL-BUILD-LAYOUT`, `VAL-NATIVE-WBOOT`, `VAL-TRANSIENT-STACK`, `VAL-GENCOM-LOADER-BOUNDARY`, `VAL-SCR-RUN-RSX`, `VAL-GUEST-FIXTURES`, `VAL-ENTRY-STATE`.

### NATIVE_TERMINAL

- Inputs: character stream, cursor coordinates, terminal parameters, or directory row data.
- Outputs: updated PCW bitmap/roller state and documented console result.
- Registers: internal helpers use AF, BC, DE, and HL; public veneers preserve the registers stated by their ABI comments.
- State: terminal parser, cursor overlay, roller RAM, font bitmap, and directory presentation state.
- Memory: public PCW screen bitmap from 5C00h plus native private terminal state.
- Design basis: `DES-TERM-001`, `DES-TERM-002`, `DES-DIR-001`, `DES-FONT-001`.
- Public basis: `REF-PCW-HARDWARE`, `REF-PCW-IO`, `REF-PCW-XBIOS`.
- Validation: `VAL-SCR-RUN-RSX`, `VAL-JOYCE-NATIVE`.

### NATIVE_DISK

- Inputs: BIOS/XBIOS registers, selected drive geometry, DMA address, and controller request.
- Outputs: controller status and CP/M-compatible success or error values.
- Registers: controller helpers use AF, BC, DE, and HL; public veneers implement their documented preservation rules.
- State: uPD765 command/result phases, motor timer, DMA transfer, disk parameters, and selected error mode.
- Memory: common DMA window, disk-parameter staging, and protected native runtime page.
- Design basis: `DES-DISK-001`, `DES-FS-A-001`, `DES-XBIOS-001`, `DES-ERROR-001`.
- Public basis: `REF-PCW-HARDWARE`, `REF-PCW-XBIOS`, `REF-CPM3-PG`.
- Validation: `VAL-MAME-NATIVE`, `VAL-XBIOS-ACTIVE-SPEC`.

### NATIVE_FILESYSTEM

- Inputs: BDOS function registers, caller FCB/DMA, active user, and selected drive.
- Outputs: updated FCB/DMA plus CP/M-compatible A, H, and extended-result values.
- Registers: dispatcher-facing routines publish their documented result; private helpers use primary registers as working state.
- State: A: extent cache, M: record map, allocation maps, passwords, labels, timestamps, and search cursor.
- Memory: caller bank through bounded mapping windows plus protected metadata and overlay regions.
- Design basis: `DES-BDOS-003`, `DES-BDOS-004`, `DES-FS-A-001`, `DES-FS-M-001`.
- Public basis: `REF-CPM3-PG`, `REF-CPM3-DISK`.
- Validation: `VAL-GENCOM-LOADER-BOUNDARY`.

### NATIVE_GENERAL

- Inputs: native dispatch registers or internal service state identified by the symbol and its caller.
- Outputs: the ABI result named by the routine or updated internal service state.
- Registers: internal routines use AF, BC, DE, and HL unless the local contract states preservation; public entries follow PUBLIC_ABI.md.
- State: native runtime, paging, keyboard, clock, shell, and compatibility-service state.
- Memory: native executable page, protected block 8, common ABI islands, and explicitly mapped caller pages.
- Design basis: `DES-NATIVE-001`, `DES-MEM-001`, `DES-LINK-001`, `DES-LINK-002`.
- Public basis: `REF-Z80-UM0080`, `REF-PCW-HARDWARE`, `REF-CPM3-PG`.
- Validation: `VAL-BUILD-LAYOUT`, `VAL-MAME-NATIVE`, `VAL-SCR-RUN-RSX`, `VAL-JOYCE-NATIVE`.
